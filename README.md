# Cryptoalegre

Public website and planning repository for Associação Cultural e Educativa Cryptolegre (Cryptoalegre).

The website is Portuguese-first, with an English version, and is currently deployed at [cryptoalegre.vercel.app](https://cryptoalegre.vercel.app).

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when contract addresses and ratification settings are available. Never commit private keys or secrets.

## Status

The constitution, membership contracts, governance execution, ENS membership resolver, and members forum remain under review. Interfaces that depend on those systems stay locked until the relevant contracts and policies are ratified, audited, and configured.
